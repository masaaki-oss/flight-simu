# ブラウザ・フライトシミュレーター

このリポジトリは、ローカルで動作する簡易フライトシミュレーターのプロトタイプです。
HTML/Canvas だけで動くため、追加の依存関係は不要です。

## 起動方法

```bash
python -m http.server
```

ブラウザで `http://localhost:8000` を開いてください。

## 操作

- W/S または ↑/↓: ピッチ
- A/D または ←/→: ロール
- Q/E: ヨー
- R/F: スロットル
- Space: ブレーキ

## 内容

- シンプルな 6DoF の力学モデル（揚力、抗力、推力、重力）
- 水平線と HUD の表示
- 速度/高度/上昇率の読み取り表示
